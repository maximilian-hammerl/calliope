Cursor

pointer — button, select, summary, label[for], and role=button / menuitem / option / tab / switch default — :disabled, [aria-disabled], [data-disabled] text — the composer and any prose
Tailwind v4's preflight dropped v3's button { cursor: pointer }. Restore it once in the base layer — never as a utility per control, or it goes missing again.
The base layer states the default; a utility is a deliberate exception. So the cursor is declared in exactly one place, and a component carries cursor-* only where it genuinely differs — shadcn's cursor-default on menu and select rows was restating Tailwind v3's default, not overriding it, so it is deleted rather than inverted. A utility always beats the base layer whatever the selector, so a leftover one silently wins; the shadcn CLI re-adds them on update, so re-check after one.
