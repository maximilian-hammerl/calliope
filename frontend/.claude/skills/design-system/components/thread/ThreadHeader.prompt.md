Head of the post list inside a thread.

```jsx
<ThreadHeader title="Kapitel 1 — Der Markt öffnet" postCount={14}
  lastActivity="vor 12 Minuten" lastAuthor="Bob" onFilter={openFilterMenu} />
```

Filter options that tested well: "Alle Beiträge", "Gemerkt", "Mit Anmerkungen". Avoid invented
categories. Never add word or character counts to the activity line.
